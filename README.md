# UP Service

Премиальный адаптивный сайт автосервиса: техническое обслуживание, диагностика и ремонт автомобилей.

**[Открыть сайт на GitHub Pages](https://levkisle123.github.io/up-service/)**

## Возможности

- Главная страница и отдельная страница предложения ТО за 4 000 ₽.
- Пять услуг с контурными иконками и тематическими изображениями.
- Плавная смена фотографий и наложение через градиентный край.
- Адаптация к мобильным экранам, навигация и форма записи.
- Поддержка уменьшенного движения и управления с клавиатуры.

## Запуск локально

Требуется Node.js 22 или новее. Установка зависимостей не нужна.

```sh
node server.mjs
```

Открыть http://127.0.0.1:4177/.

## Структура

- `dist/index.html` — общий HTML.
- `dist/app.js` — страницы, форма и интерактивность.
- `dist/style.css` — стили и анимации.
- `dist/config.js` — услуги, контакты и настройки формы.
- `dist/assets/` — локальные изображения и логотип.
- `dist/to-4000/index.html` — прямой переход на страницу предложения.
- `server.mjs` — небольшой сервер для локального просмотра.
- `scripts/build-pages.mjs` — подготовка путей для GitHub Pages.
- `docs/` — опубликованная версия сайта для GitHub Pages.

## Обновление GitHub Pages

После изменений в `dist/` выполните `node scripts/build-pages.mjs` и отправьте обновлённые `dist/` и `docs/` в ветку `main`. В настройках Pages выбран источник `main` → `/docs`. Изображения, навигация и отдельная страница ТО поддерживают адрес проекта `/up-service/`.

## Статус демоверсии

Контакты и график демонстрационные. Отправка заявок отключена: данные не передаются и не сохраняются. Для запуска приёма заявок нужны реальные контакты, утверждённые условия предложения, политика обработки персональных данных и серверный получатель заявок.

Изображения процедур и автомобиля созданы с помощью ИИ. Они не являются фотографиями помещений или выполненных работ UP Service. Логотип предоставлен заказчиком. Шрифты Manrope и Unbounded загружаются через Google Fonts; контурные иконки — Hugeicons Free Stroke Rounded.
